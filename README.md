# Convert svg to png

## Overview 
> This project is used to convert svg file into png file. The converted filr also upload to s3 bucket.

## Installation

```console
npm install
```


## Run

> To build in development environment

```console
npm build
```

> To start server

```console
npm start
```

> To start server in development environment

```console
npm run dev
```

## Packages used

* express
	* express is used for server.
* convert-svg-to-png
  * convert-svg-to-png is used for file convert.
* aws-sdk
  * aws-sdk is used for connect to s3 bucket.
